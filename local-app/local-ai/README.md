# Локальный обученный ИИ Asyl As

Используется **multilingual-e5-small после градиентного дообучения, с проверкой меток исследователем**. Модель различает жалобы, положительные отзывы и недостаток информации. Точную причину уточняет исследователь по тексту и анкете. Это узкий классификатор, не универсальный чат-бот.

## Запуск

В корне проекта откройте **Start-Asyl-Local.cmd**. Приложение: http://127.0.0.1:5174/. Отчёт: http://127.0.0.1:5174/training.

Нажмите «Локальный анализ», сверьте категории с текстами, исправьте ошибки и нажмите «Проверил категории — показать рекомендации». Для остановки модели и освобождения видеопамяти — **Stop-Asyl-Local.cmd**.

Записи находятся в `local-data/asyl.sqlite`, журналы — `local-data/model.log` и `local-data/app.log`. Перед резервным копированием базы остановите приложение. Локальные записи не синхронизируются с онлайн-сайтом.

## Что обучено и какие ограничения

Испытаны Qwen3-1.7B + LoRA и multilingual-e5-small. Все результаты сохранены, включая слабые. В выбранной E5 обучались два последних Transformer-слоя и классификатор, около 3.55 миллиона параметров. Это реальное изменение весов градиентом, не только настройка запроса.

128 учебных отзывов использовались для обучения, 32 — для выбора версии. Первый контрольный набор из 48 примеров и последующий из 64 сохранены отдельно. Все тексты составлены ассистентом; реальных наблюдений учеников нет. Разметку и казахский текст должен проверить исследователь/носитель языка.

Распознавание восьми точных причин оказалось недостаточным. Для приложения задача упрощена до трёх категорий. На 64 искусственных примерах результат изменился с 53/64 до 55/64. Это разработческая оценка, не независимый полевой тест. Автоматический режим не прошёл порог macro F1 0.80; приложение требует проверки меток человеком. Показатели трёх категорий нельзя выдавать за точность восьми причин.

Подробности — **TRAINING_REPORT.md**. В `runs/` находятся протоколы, история, веса, метрики и ошибки каждого прогона. `active.json` указывает выбранные веса и обязательность проверки. Расчёт массы отходов и тексты действий выполняет отдельная логика приложения.

## Воспроизводимость

Использовано отдельное окружение `.venv`, Python 3.12, RTX 3050 Laptop 6GB. Точные библиотеки — `requirements-lock.txt`. Системный Python не изменён. Интернет нужен для первоначальной загрузки библиотек и весов. Запуск использует `HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1`, `local_files_only=True` и `trust_remote_code=False`. Сервисы слушают только 127.0.0.1; внешние шрифты в локальную сборку не включены.

Для повторения из корня проекта:

```powershell
local-ai/.venv/Scripts/python.exe local-ai/test_dataset.py
local-ai/.venv/Scripts/python.exe -u local-ai/train_e5.py
```

`select_triage.py` документирует укрупнение категорий и сравнение по validation. Флаг `--reviewed-prototype` включает обязательную проверку человеком и не меняет проваленный критерий автоматического режима. Скрипт ссылается на конкретные сохранённые запуски; для нового опыта нужно обновить пути на полученные из `train_e5.py`. `train.py` и Qwen сохранены для воспроизведения альтернативы с LoRA.

Перед обучением остановите локальный сервис. Для нового компьютера нужны совместимый CUDA-выпуск PyTorch из официального репозитория, зависимости `requirements.txt` и базовые веса. `download_model.py` сохраняет commit исходной модели. Базовая E5: https://huggingface.co/intfloat/multilingual-e5-small, MIT.

Для улучшения качества нужны новые анонимные реальные отзывы, независимая разметка, заранее фиксированная задача и новый тест. В конкурсной работе укажите помощь ассистента и собственный вклад.
