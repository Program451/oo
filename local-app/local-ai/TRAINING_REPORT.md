# Asyl As: результаты реального дообучения

Выбрана **intfloat/multilingual-e5-small** (MIT). Она помогает отделить жалобы от положительных отзывов и текстов с недостатком информации. Конкретную причину подтверждает исследователь. Это узкий классификатор, не универсальный чат-бот.

## Обученные веса

Градиентом дообучены два последних слоя Transformer и линейный классификатор. Обучаемых параметров: 3,552,008. В сохранённой версии фактически изменилось 3,551,992 значений. Остальные слои заморожены.

Внутри модель обучалась на восьми темах. Подробное распознавание оказалось недостаточным. После анализа ошибок задача приложения упрощена до трёх категорий: **жалоба / положительный отзыв / недостаточно информации**. Их показатели нельзя выдавать за точность распознавания восьми причин.

## Данные и проверка

128 учебных отзывов использованы для градиентов, 32 других — для выбора версии, 64 — для контрольного сравнения. Все тексты составлены ассистентом на русском и казахском; реальных отзывов учеников нет.

| Три категории | До дообучения | После дообучения |
|---|---:|---:|
| Верных ответов из 64 | 53 | 55 |
| Доля верных ответов | 82.8% | 85.9% |
| Macro F1 | 0.751 | 0.777 |

Базовое сравнение — фиксированная E5 с центрами классов по обучающим примерам, без градиентного обновления слоёв. Предсказание только самой частой категории дало бы 75%. Прирост составил два правильных ответа; статистически значимое преимущество не заявляется.

95% интервал Wilson для итоговой доли верных ответов: 75.4% — 92.4%. Он не устраняет смещение искусственной выборки. Контрольные данные не использовались для градиентов, но задача уточнялась при разработке. Это **разработческая оценка, не независимый тест реальной школы**. Разметку и казахские формулировки должен проверить исследователь/носитель языка.

На validation из 32 примеров первичный разбор дал 31 правильный ответ. По этой выборке E5 выбрана вместо Qwen. Итоговая macro F1 ниже порога 0.80: **автоматический режим не прошёл критерий**, поэтому приложение требует подтверждения или исправления меток перед рекомендациями.
