# Asyl As — столовая без потерь

Локальная программа исследователя и отдельный публичный сайт для учеников.

## Как пользоваться

1. Откройте `Start-Asyl-Local.cmd`. Программа доступна на http://127.0.0.1:5174.
2. В «Мои данные» добавьте реальные измерения. Демонстрационные цифры хранятся отдельно.
3. Откройте «Сбор отзывов», создайте опрос об обеде или голосование за предложенные блюда.
4. Скачайте QR-код или откройте плакат для печати. Ссылка работает через интернет, даже когда ваш компьютер выключен.
5. Нажмите «Загрузить ответы». Отзывы появятся в «Отзывы учеников» → «Мои данные». Голоса остаются в разделе опросов.
6. «AI-помощник» → «Локальный анализ». Проверьте и при необходимости исправьте предложенные категории. Если текстовых комментариев нет, оценки, причины и измерения разбираются по правилам, без запуска модели и пустого списка проверки.
7. Экспорт CSV выгружает отзывы на вкладке отзывов и измерения на остальных вкладках. Результаты выбранного голосования скачиваются отдельной кнопкой в «Сбор отзывов»: варианты, голоса, проценты и время последней загрузки. Перед экспортом обновите ответы. «Резервная копия» сохраняет JSON с исследованием, опросами и голосами, без ключа доступа.

Для остановки используйте `Stop-Asyl-Local.cmd`.

## Две части системы

- **На компьютере:** SQLite `local-data/asyl.sqlite`, измерения, эксперименты, графики, дообученная модель. Сервер слушает только 127.0.0.1.
- **На сайте:** анонимные ответы и голоса. Имена и контакты не запрашиваются. Публичная форма не показывает чужие ответы.
- **Подключение:** сервер программы скачивает ответы по защищённому API. Измерения и веса модели на сайт не отправляются. Интернет требуется для создания/закрытия опросов и загрузки ответов, а локальный анализ работает без облачного API.
- Одна отправка на опрос с одного браузера. Это не проверка личности: другой браузер или устройство может дать дополнительный голос. Результаты не следует выдавать за число уникальных учеников.
- Предлагаемые блюда согласует ответственный за питание. Голосование не изменяет меню автоматически.

Сайт: https://asyl.studynesthub.com. Его исходники находятся в соседней папке `feedback-site` опубликованного репозитория. Старый частный прототип с Gemini является отдельной версией.

## Установка на другом компьютере

Требуется Node.js 24 и Python 3.12. Для журнала, графиков и опросов модель необязательна.

```powershell
npm ci
npm run local:build
npm run local:start
```

Подготовка модели описана в `local-ai/README.md`. Базовые веса загружаются отдельно из официального репозитория Hugging Face. Дообученные веса и протокол выбранного запуска приложены в репозитории.

Секрет подключения хранится в игнорируемом `local-data/feedback-connection.json`:

```json
{"url":"https://asyl.studynesthub.com","token":"64_HEX_CHARACTERS_GENERATED_LOCALLY"}
```

На сервере сайта настраивается только SHA-256 этого токена (`ADMIN_TOKEN_HASH`). Настоящий токен не передаётся браузеру, не включается в QR-код, Git или резервную копию. Для нового компьютера переносите файл подключения отдельно и только владельцу исследования.

## Проверка

```powershell
npm run local:build
npx tsc --noEmit
npm run test:local
```

Тесты локального API используют отдельный порт 5176 и отдельную базу в outputs. Основные записи пользователя не меняются.

Сквозная проверка двух частей (в монорепозитории сначала соберите `feedback-site` командой `npm run build:node`):

```powershell
npm run test:feedback-flow
```

Она запускает настоящий HTTP-сервис на 5190 и локальную программу на 5191 с отдельными SQLite-базами. Проверяет создание опросов, QR-ссылку, повторную отправку, импорт, сохранение курсора после перезапуска, разделение голосов и отзывов, CSV, завершение опроса и доступность сохранённых результатов без сайта. Для другой структуры каталогов задайте `ASYL_FEEDBACK_SITE` — путь к исходникам сайта. Для включения проверки работающей дообученной модели сначала запустите основную программу и установите `ASYL_TEST_MODEL=1`. Содержимое и токены рабочей базы в тестах не используются.

## Научные ограничения

Модель multilingual-e5-small реально дообучена, но только на 128 искусственных учебных примерах. В трёх категориях на 64 разработческих примерах получено 55 правильных ответов вместо 53 до дообучения. Это не независимая оценка качества в школе. Автоматический режим не прошёл критерий; категории проверяет исследователь. Подробности и ошибки — в `local-ai/TRAINING_REPORT.md`.

Расчёты массы и текст действий формируются проверяемым кодом. Новые отзывы не переобучают модель автоматически. Снижение отходов необходимо доказать реальными наблюдениями при сопоставимых условиях. Код и учебные примеры подготовлены с помощью ИИ-ассистента; личный вклад участника исследования нужно описать отдельно.
