# Asyl As — кабинет на сайте, ИИ на ноутбуке

Кабинет исследователя: https://cabinet.asyl.studynesthub.com

Сайт отзывов учеников: https://asyl.studynesthub.com

## Как пользоваться

1. Откройте кабинет и введите личный код входа. На подготовленном ноутбуке он сохранён в `local-data/Код входа в кабинет.txt`. Не передавайте его ученикам.
2. Добавляйте измерения, создавайте опросы и голосования, печатайте QR-коды. Для этих функций запуск программы на ноутбуке не нужен.
3. В открытом разделе «Сбор отзывов» ответы обновляются автоматически каждые 15 секунд и при возвращении на вкладку. Голоса за каждое блюдо и проценты видны прямо в карточке опроса, рядом доступен CSV. Для немедленного обновления нажмите «Обновить сейчас». При временной ошибке связи последние результаты сохраняются на экране; загрузка повторится автоматически.
4. Для анализа текста запустите **Start-Asyl-AI.cmd** на подготовленном ноутбуке. Дождитесь сообщения о подключении. В кабинете появится индикатор «ИИ на ноутбуке подключён».
5. В «AI-помощник» нажмите «Анализ отзывов». Ноутбук классифицирует до 24 текстов по 300 символов. Проверьте категории перед рекомендациями.
6. Остановить модуль можно закрытием его окна или через **Stop-Asyl-AI.cmd**. Кабинет, опросы, графики и экспорт остаются доступны. Анкеты без текстовых комментариев разбираются по правилам и не требуют работающего ИИ.

## Готовый архив для Windows

В выпуске [v0.3.0](https://github.com/Program451/oo/releases/tag/v0.3.0) доступен `Asyl-AI-Windows-x64.zip`: модель, встроенный Python и PyTorch для процессора уже включены. Подходит для Windows 10/11 x64; отдельная установка Python и CUDA не нужна. Рекомендуется 8 ГБ ОЗУ и 3 ГБ свободного места. Распакуйте архив целиком, добавьте личную папку `local-data` из отдельного архива настроек и откройте `Start-Asyl-AI.cmd`. Диагностика — `Check-Asyl-AI.cmd`, остановка — `Stop-Asyl-AI.cmd`.

Общий архив GitHub не содержит кода входа или токена. Личный архив `Asyl-AI-Windows-My-Cabinet.zip` уже настроен, хранится только у владельца и не публикуется. Его нельзя передавать ученикам. Интернет нужен для связи с кабинетом; вычисления выполняются на ноутбуке. Во время работы оставьте окно запуска открытым.

Сборка переносимой версии: `scripts/package-laptop.py` принимает официальный встроенный Python 3.12.10 x64 и CPU-wheel PyTorch 2.7.1 для CPython 3.12. Остальные зависимости копируются из проверенной среды проекта вместе с лицензиями. После проверки запуска `scripts/archive-laptop.py` создаёт общий ZIP; флаг `--personal` дополнительно создаёт личные архивы вне Git. Никогда не загружайте личные архивы в релиз.

## Где находятся данные

Измерения, эксперименты, скачанные отзывы и результаты голосований сохраняются на сервере проекта в закрытом кабинете. Ученики видят только форму опроса по QR-ссылке. Для анализа выбранные тексты передаются модулю ИИ на ноутбуке; результаты возвращаются на сайт. Ноутбук сам подключается по HTTPS, входящие порты не открываются. Сторонние API искусственного интеллекта не используются.

Код входа и токен ноутбука различаются. Токен ноутбука даёт доступ только к заданиям ИИ, а не к измерениям, резервным копиям или управлению опросами. Сессия кабинета действует 8 часов. При отключении ноутбука сайт показывает состояние ИИ и не придумывает результат анализа.

Настройки ноутбука хранятся в игнорируемом `local-data/remote-worker.json`. Серверу передаётся только хэш токена ноутбука. Пароли, токены и реальные отзывы не входят в Git.

## Дообученная модель

Используется исходная дообученная **intfloat/multilingual-e5-small** с весами `local-ai/runs/e5-20261104T193236Z/weights.safetensors`. 128 искусственных обучающих примеров и 32 примера для выбора версии. На разработческой трёхкатегорийной проверке: 55/64 вместо 53/64 до дообучения. Это не независимая оценка реальной школы. Категории проверяет исследователь, расчёты и действия формирует код. Голосование показывает предпочтения, а снижение отходов подтверждается реальными измерениями.

Подготовка среды и базовых весов на новом ноутбуке описана в `local-ai/README.md`. Файл подключения переносится отдельно только владельцу проекта. Уже установленная среда ноутбука готова к запуску.

## Разработка и проверки

Для сборки кабинета требуется Node.js 24:

```sh
npm ci
npm run local:build
npm run build:web
npm run test:local
npm run test:web
```

Сборка для сервера находится в `outputs/hosted-app`. В Docker не устанавливаются зависимости обучения: он содержит только кабинет и очередь заданий ИИ. Проверки кабинета используют временную SQLite-базу и порт 5193. Сквозной тест двух частей запускается `npm run test:feedback-flow` после сборки соседнего `feedback-site`; порты 5190–5191, отдельные учебные базы. Для другой структуры папок задайте `ASYL_FEEDBACK_SITE`.

Полностью локальная версия сохранена как дополнительный режим: `Start-Asyl-Local.cmd`, http://127.0.0.1:5174. Для основной работы используется веб-кабинет.
