# Asyl As — школьная столовая без потерь

**Кабинет исследователя:** https://cabinet.asyl.studynesthub.com

**Отзывы учеников по QR:** https://asyl.studynesthub.com

Кабинет работает на сайте без запуска локальной программы. Только модуль ИИ запускается на ноутбуке файлом `Start-Asyl-AI.cmd`. Он получает задания по защищённому HTTPS-соединению и возвращает категории отзывов. Когда ноутбук выключен, кабинет, измерения, опросы и голосования продолжают работать; текстовый анализ сообщает о недоступности ИИ.

## Использование

1. Войти в кабинет личным кодом организатора.
2. Добавлять измерения и создавать опросы в «Сбор отзывов».
3. Разместить QR-код в столовой. В открытом разделе «Сбор отзывов» результаты обновляются каждые 15 секунд; число голосов за каждое блюдо видно прямо в карточке. Кнопка «Обновить сейчас» позволяет загрузить ответы сразу.
4. Для ИИ запустить `Start-Asyl-AI.cmd` на подготовленном ноутбуке и нажать «Анализ отзывов» в кабинете.
5. Проверить категории модели и сопоставить выводы с измерениями до и после согласованного изменения.

Результаты опросов выгружаются в CSV. Код входа не предназначен ученикам. На подготовленном ноутбуке он хранится отдельно в `local-data/Код входа в кабинет.txt`, вне репозитория.

Готовая версия для Windows x64: [скачать архив ИИ](https://github.com/Program451/oo/releases/download/v0.3.0/Asyl-AI-Windows-x64.zip). Внутри Python, модель и библиотеки для работы на процессоре. Распакуйте целиком, добавьте личные настройки подключения и запустите `Start-Asyl-AI.cmd`. Личный архив с уже заполненными настройками передаётся владельцу отдельно и не публикуется. Подробности — `local-app/README.md`.

## Состав

- `local-app` — исходники кабинета, защищённого серверного API и модуля ИИ для ноутбука. Название каталога сохранено; он также содержит дополнительный полностью локальный режим.
- `feedback-site` — отдельный сайт учеников на русском и казахском.
- `deploy/install-research.sh` — установка нового контейнера кабинета на проверенный существующий сервер.
- `deploy/install-existing.sh` — первоначальная установка сайта отзывов.

Подробные команды сборки и тестов — в `local-app/README.md` и `feedback-site/README.md`. Сборка кабинета: Node.js 24, `npm ci`, `npm run local:build`, `npm run build:web`. Для ноутбука используется установленная Python-среда и базовые веса из официального репозитория Hugging Face.

## Модель и исследование

**intfloat/multilingual-e5-small**: градиентом дообучены последние два Transformer-слоя и классификатор, около 3,55 млн параметров. 128 искусственных обучающих примеров, 32 для выбора версии. На трёхкатегорийной разработческой проверке — 55/64 вместо 53/64 до дообучения. Категории: жалоба, положительный отзыв, недостаточно информации.

Это исследовательский прототип: автоматический режим не прошёл критерий допуска, метки проверяет человек. Проверка на реальных школьных отзывах ещё нужна. Расчёты отходов и действия формируются правилами программы. Голосование показывает предпочтения участников, а не доказанное снижение отходов. Учебные цифры нельзя выдавать за эффект в школе.

Дообученные веса и протокол: `local-app/local-ai/runs/e5-20261104T193236Z`. Код и синтетические примеры подготовлены с помощью ИИ-ассистента; личный вклад автора исследования необходимо описать отдельно.

Секреты, реальные данные, базовые модели и виртуальная среда исключены из Git. Модуль ноутбука имеет отдельный токен только для заданий ИИ. Публичное чтение отзывов и исследовательской базы закрыто. Не собирайте имена, контакты и сведения о здоровье.
