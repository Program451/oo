# Asyl As — школьная столовая без потерь

Система разделена на две части:

- `local-app` — локальная программа исследователя: измерения, графики, эксперименты, скачивание отзывов, голосования и локальный ИИ.
- `feedback-site` — отдельный сайт учеников на русском и казахском: отзыв об обеде или выбор одного из предложенных блюд по QR-коду.

Рабочий адрес сайта: **https://asyl.studynesthub.com**. Форма открывается по индивидуальному QR-коду опроса, который создаётся в локальной программе. Главная страница без кода показывает объяснение.

## Запуск программы

Требуется Node.js 24. В каталоге `local-app`:

```sh
npm ci
npm run local:build
npm run local:start
```

Открыть http://127.0.0.1:5174. На подготовленном Windows-компьютере достаточно `Start-Asyl-Local.cmd`.

Интернет нужен для создания опроса, получения QR-ссылки и скачивания ответов. Журнал и локальный анализ работают отдельно от сайта. Компьютер исследователя можно выключать: сайт продолжит принимать ответы.

## ИИ и честная оценка

База — **intfloat/multilingual-e5-small**. Градиентом дообучены последние два Transformer-слоя и классификатор, около 3,55 млн параметров. 128 искусственных обучающих примеров; 32 для выбора версии; 64 разработческих контрольных примера.

В приложении три категории: жалоба, положительный отзыв, недостаточно информации. На учебной проверке — 55/64 против 53/64 до дообучения. Это не независимая оценка реальных школьных отзывов. Автоматический режим не прошёл заданный критерий; пользователь обязательно проверяет категории. Расчёты отходов и действия определяются кодом, а не свободной генерацией.

Выбранные дообученные веса, протокол и отчёт сохранены в `local-app/local-ai/runs/e5-20261104T193236Z`. Базовые веса загружаются отдельно из официального источника, инструкция — в `local-app/local-ai/README.md`.

## Публикация

Публичный сервис собирается командой `npm run build:node` в `feedback-site`. Runtime: Node.js 24 + SQLite в постоянном каталоге `/data`. Dockerfile не выполняет обучение и не содержит ключей. Для установленного сервера предусмотрен ограниченный сценарий `deploy/install-existing.sh`: отдельный контейнер и добавление одного маршрута Caddy с резервной копией. Скрипт не является универсальным установщиком для других серверов.

Секреты, реальные ответы, исходные пароли, базовые модели и виртуальное окружение в репозиторий не входят. Нужен отдельный серверный токен для связи локальной программы с сайтом. Сайт не предоставляет публичного чтения результатов.

## Исследовательские ограничения

Голосование показывает предпочтения участников, а не доказанное снижение отходов. Один браузер может отправить один ответ на опрос, но анонимный сбор не гарантирует уникальность людей. Варианты меню согласует ответственный за питание. Не собирайте имена, контакты и сведения о здоровье.

Результат проекта подтверждается реальными измерениями и сопоставлением условий. Учебные цифры нельзя выдавать за эффект в школе. Код и синтетические примеры подготовлены при помощи ИИ-ассистента; автору исследования необходимо показать собственный вклад.
