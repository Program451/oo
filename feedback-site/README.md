# Asyl As — публичный сбор отзывов

Отдельная страница для учеников на русском и казахском. Два типа опросов: отзыв о поданном блюде и голосование за варианты меню. Управление осуществляется только из локальной программы.

## Сборка для DigitalOcean

Требуется Node.js 24.

```sh
npm ci
npm run build:node
npm run test:service
```

Сборка находится в dist-node. Рабочий сервер: `node scripts/server-node.mjs`. Dockerfile использует готовую сборку; устанавливать npm-пакеты на рабочем сервере не требуется.

Настройки окружения:

- PUBLIC_ORIGIN — точный HTTPS-адрес сайта без завершающего слеша.
- ADMIN_TOKEN_HASH — SHA-256 32-байтового случайного токена локальной программы, представленного строкой из 64 hex-символов. Сам токен не хранится в исходниках.
- PORT=8095, BIND=0.0.0.0 — внутри контейнера.
- DATA_DIR=/data — постоянный каталог SQLite, подключённый с хоста.
- TRUST_PROXY=1 — только за доверенным обратным прокси; контейнер не публикуется напрямую в интернет.

## Границы доступа

Публичный API отдаёт только параметры опроса и принимает ответы. Чтение результатов, создание и закрытие защищены серверным токеном. Ответы привязаны к опросу, варианты проверяются на сервере. Повторная отправка из браузера идемпотентна; закрытый опрос новые ответы не принимает.

Ограничения: до 200 опросов, 5000 ответов на опрос, 8 блюд, 300 символов комментария, до 14 дней на опрос. Ограничитель потока допускает 300 ответов в минуту с одного адреса; хранит только краткоживущий хэш, исходный IP не записывается в таблицы приложения. Служебные журналы хостинга могут обрабатываться провайдером отдельно.

Без регистрации невозможно надёжно считать уникальных людей. Очистка хранилища браузера или другое устройство допускают повторное участие. Для серьёзных выводов проверяйте выборку и сопоставляйте голоса с реальными измерениями.

Данные сохраняются на сервере в SQLite и скачиваются исследователем. Не собирайте имена, контакты, классы или сведения о здоровье. Локальный ИИ и измерения в этот сервис не загружаются.

## Резервирование

Файл `/data/feedback.sqlite` и его WAL — рабочая база. Для согласованной копии используйте SQLite backup API; не копируйте только основной файл при работающем WAL. Снимок исследовательских данных можно скачать из локальной программы. Секрет подключения хранится и переносится отдельно.

Исходные маршруты Vinext/D1 сохранены как альтернативный адаптер. Текущая целевая публикация — Node.js + SQLite на существующем сервере DigitalOcean, без создания нового платного ресурса.
