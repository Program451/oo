## Сервер

Использован существующий Droplet; новый платный ресурс не создавался. Контейнер `asyl-feedback`, образ `asyl-feedback:0.2.0`, сеть `birge_default`. Ограничения: 160 MiB памяти, 0,35 CPU, 64 процесса. После запуска фактическое потребление памяти составило около 40 MiB.

Файлы проекта находятся только в `/opt/asyl-as-feedback`:

- `releases/v0.2.0` — проверенная по контрольной сумме сборка;
- `data/feedback.sqlite` — постоянная база отзывов и голосов;
- `server.env` — закрытые настройки, не публиковать;
- `backups/Caddyfile.20261104T205156Z` — конфигурация прокси перед установкой.

В `/opt/birge/Caddyfile` добавлен только блок `asyl.studynesthub.com`. Существующие блоки не изменились; Caddy перечитал конфигурацию без перезапуска контейнера. В Spaceship добавлена одна A-запись `asyl`, остальные записи сохранены.

Повторно запускать `install-existing.sh` поверх установки не нужно: он намеренно останавливается при наличии контейнера или маршрута. Для обновления сначала подготовьте новую сборку и согласованную резервную копию SQLite; инструкция по резервированию — в `feedback-site/README.md`.

## Начало работы

На подготовленном компьютере открыть `asyl-as/Start-Asyl-Local.cmd`, затем http://127.0.0.1:5174. В разделе «Сбор отзывов» нажать «Создать опрос», выбрать отзывы либо голосование, указать настоящие блюда и срок. Разместить полученный QR-код в столовой. Кнопка «Загрузить ответы» переносит новые ответы в локальную программу без повторного импорта.

До первого опроса главная страница сайта просит открыть QR-ссылку. Рабочая база при публикации пустая: учебные отзывы из тестов в неё не переносились. Сайт принимает ответы и при выключенном компьютере исследователя. Измерения и модель остаются на компьютере.

## Проверки

23 автоматических теста, проверки TypeScript и сборки обеих частей прошли. Формы отзывов и голосования проверены в отдельной тестовой базе. На рабочем сайте `/healthz` отвечает 200, административный API без токена — 401. Синхронизация из локальной программы успешна; локальная модель сообщает готовность.

После установки главные страницы основного домена и поддоменов `agro`, `chat`, `edu`, `mathlab`, `support` ответили HTTP 200. Их контейнеры не перезапускались.

Дообученная модель остаётся исследовательским прототипом: категории отзывов проверяет человек, а качество на реальных школьных данных ещё предстоит оценить.
